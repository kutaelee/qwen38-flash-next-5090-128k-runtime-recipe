# Publishing guide

GitHub is the canonical source. The repository stores only the reviewed X image asset; post copy remains outside the public repository.

Before publishing:

1. Confirm the 100K+ context result and the recorded MTP rejection remain accurately described.
2. Trace every benchmark value to preserved private evidence.
3. Run `pwsh -NoProfile -File .\scripts\validate-release.ps1`.
4. Review the full Git diff and Git history for local paths, usernames, job IDs, private prompts or outputs, internal repository details, logs, and model files.
5. Recheck upstream links and licenses.
6. Create the empty public repository without autogenerated files, then push the reviewed local repository.
